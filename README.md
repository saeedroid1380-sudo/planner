# آرامش

برنامه‌ی روزانه، عادت‌ها، یادداشت‌ها و مناسبت‌ها — قابل نصب روی گوشی (PWA) و آفلاین.


## چطور روی گوشی نصبش کنم؟

- **اندروید (کروم):** آدرس بالا رو باز کن، از منوی سه‌نقطه گزینه‌ی «Add to Home screen» یا «Install app» رو بزن.
- **آیفون (سافاری):** آدرس رو باز کن، دکمه‌ی Share (مربع با فلش رو به بالا) رو بزن، بعد «Add to Home Screen».

بعد از نصب، برنامه مثل یک اپ مستقل روی گوشی میاد و حتی بدون اینترنت هم باز می‌شه و کار می‌کنه (اطلاعات داخل خود گوشی ذخیره می‌شن، نه روی سرور).

## نکته

اگه بعداً فایل `index.html` رو عوض کردی، برای اینکه گوشی‌هایی که قبلاً نصبش کردن نسخه‌ی جدید رو بگیرن، کافیه شماره‌ی `CACHE_NAME` رو توی `sw.js` عوض کنی (مثلاً از `aramesh-v1` به `aramesh-v2`).
